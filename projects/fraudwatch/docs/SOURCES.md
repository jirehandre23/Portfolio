# Primary technical references

Consulted during implementation, 2026-10-14. Dependency versions are deliberately
pinned for this reference build; the links may describe newer releases.

- [XGBoost parameters](https://xgboost.readthedocs.io/en/stable/parameter.html): binary logistic objective and tree parameters.
- [MLflow PythonModel](https://mlflow.org/docs/latest/ml/model/python_model/): wrapper load/predict lifecycle, artifacts and signatures.
- [FastAPI concurrency](https://fastapi.tiangolo.com/async/): awaited I/O versus synchronous computation.
- [Flink 1.20 Kafka SQL connector](https://nightlies.apache.org/flink/flink-docs-release-1.20/docs/connectors/table/kafka/): table connectors, offset initialization and delivery semantics.
- [Flink connector artifact 3.3.0-1.20](https://repo.maven.apache.org/maven2/org/apache/flink/flink-sql-connector-kafka/3.3.0-1.20/): connector/runtime version compatibility.
- [Apache Kafka 3.9 quickstart](https://kafka.apache.org/39/getting-started/quickstart/): official Docker image.
- [scikit-learn average precision](https://scikit-learn.org/1.5/modules/generated/sklearn.metrics.average_precision_score.html): AP definition and distinction from trapezoidal area.
- [Docker Compose services](https://docs.docker.com/reference/compose-file/services/): health and completion dependency conditions.

No external fraud dataset is redistributed. Synthetic data is generated by this repository.
