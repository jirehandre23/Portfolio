The question

What is in the catalog?

Compare movie and TV title counts, release years, country credits and genre memberships.

How are fields interpreted?

Split multi-country labels, parse numeric durations and handle mixed date formats before drawing conclusions.

What can the data support?

Catalog composition describes supply. This dataset has no viewing, subscriber, retention or revenue measurements.

What changed after review?
Numeric comparisons
The longest movie is selected by parsed minutes instead of alphabetically sorting duration text. The source metadata contains a 312-minute entry.
Reproducible dates
Queries handle both short and long textual addition dates and anchor rolling windows to the snapshot rather than today's date.
Verified queries
All 15 revised queries were executed against the included CSV using PostgreSQL via PGlite.
Historical catalog snapshot. Co-production counts are nonexclusive, and keyword matches are not quality or audience-suitability judgments. This project is independent of Netflix.
Dataset reference: Shivam Bansal’s Netflix dataset. Source CSV and validation evidence are in the repository.
